## Memory

This repo has a shared notebook in [`memory/`](memory/README.md). It holds what
agents learned while working here that the code can't tell you: decisions and their
reasons, unwritten conventions, known traps, and approaches that didn't work.

Read `memory/README.md` and the notes relevant to your task before you start. Treat a
note as a lead, not a fact: check its evidence against the current code before you
rely on it, and fix or remove it if the code disagrees. When you learn something a
future session would otherwise have to rediscover the hard way, write it down.
